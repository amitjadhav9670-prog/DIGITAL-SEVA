# Digital Seva Center
Open `index.html` in a browser or deploy the folder to GitHub Pages/Netlify/Vercel.

Included:
- Service cards and search
- Document/PDF/image print tool interface
- Passport photo tool interface
- Photo frame sizes
- Admin demo panel for services and WhatsApp setting
- Responsive UI

Note: This is a front-end prototype. A production admin login, database, server-side file processing, secure PDF processing and real background-removal API should be added before public deployment.
